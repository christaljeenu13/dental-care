#  Dental Care Clinic

A modern and professional **Dental Clinic Landing Page** created using **HTML5**.

##  Project Description

Dental Care Clinic is a single-page website designed to showcase a dental clinic, its services, smile transformations, and patient enquiry options.

The entire project is contained in a single HTML file.

##  Features

* Attractive landing page
* Dental services showcase
* Interactive before-and-after section
* Why Choose Us section
* Patient enquiry form
* Clinic contact information
* Responsive design
* Modern dental clinic interface
* Appointment call-to-action

## Technology Used

* **HTML5**

## Project Structure

```text
Dental-Care-Clinic/
│
├── index.html
│
└── README.md
```

##  How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any web browser.
4. The Dental Care Clinic website will be displayed.

No installation or additional software is required.

##  Enquiry Form
